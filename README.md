## Profile photo
Your supplied photo is included at `assets/profile.jpg` and displayed in the existing homepage portrait frame. To change it later, replace that file with another photo using the same filename.

## Upload to your existing GitHub repository
1. Extract this ZIP.
2. Open `https://github.com/saqibahmedofficial/Demo`.
3. Click **Add file → Upload files**.
4. Upload all files and folders inside `saqib-portfolio-updated-src` to the repository root (not the enclosing folder itself). Make sure the `assets` folder and `assets/profile.jpg` are included.
5. Click **Commit changes**.
6. Keep GitHub Pages configured as **Deploy from a branch → main → /(root)**.
7. Your website URL remains `https://saqibahmedofficial.github.io/Demo/`.

All resume-based experience, education, certifications, skills, tools and project areas are included. No unverified performance results or metrics have been added.
